# C5 DOTA2 挂刀买入推荐 0.3.3

你的目标口径为 **总买入成本 / Steam扣手续费后到账，越低越好**。0.77是参考值，不是硬门槛。默认优先推荐单件C5买入价至少200元的饰品，减少交易笔数；可在设置中调整价格区间。低于200元不进入排序表格。正式推荐仍要求费后到账高于总成本，即成本比例小于1。与0.1.0采用的“Steam到账/成本”方向相反。

## 安装与使用

1. 下载本私有仓库的 c5-steam-ratio.user.js，在Tampermonkey添加新脚本并粘贴全文保存。已有同名脚本请替换，避免两个版本同时运行。
2. 在同一Chrome正常登录C5和Steam，打开 https://www.c5game.com/dota2 。面板应显示“C5 → Steam 买入推荐”。
3. 点击查询本页；每批最多10件、20次请求，串行间隔至少5秒。再次点击会继续查询尚未取得新鲜数据的商品。
4. 默认排序表格仅显示200元及以上商品，全部按成本比例升序，推荐状态不会改变比例顺序。表格显示买入价、预计到账、成本比例、成交量、求购到账、顶档数量及达到参考比例的买入上限。可以设置参考比例、最低买入价、成交量、价差、额外成本和售价上限，也可只看推荐。
5. 若盘口币种仍不是CNY，打开表格里的“Steam核验”链接。在正常打开的Steam饰品页点击“将本页求购报价用于C5推荐”，然后返回C5调整筛选或重新查询。只接收对应marketHashName且5分钟内的数据；旧页面需正常刷新。

脚本仅推荐，不购买、不交易、不翻页、不改变账号币种。私有仓库下载地址可能含短期访问令牌，不能作为长期自动更新地址。

## 推荐含义

- **求购可成交候选**：挂售估算和最高求购扣费后到账均高于总成本；人民币盘口新鲜、顶档有数量、价差小、近期成交量充足。
- **挂售候选**：按保守挂售估算到账高于成本，人民币盘口和成交量支持进一步核验，但当前求购扣费后到账尚未高于成本，需要挂售等成交。
- **价格达标、流动性待核验**：挂售价估算达标，求购币种/深度/价差等未确认，不作为正式推荐。
- **未达标对照**：帮助看出需要降到什么买入价才达到0.77参考值，不代表建议买入。无推荐是合法结果。

默认成交量至少30、盘口价差不超过5%、最低挂单与成交中位价偏差不超过15%、单件C5价至少200元、不超过5000元（可调整）。只扫描当前可见列表，不声称是全市场最优。成交量不会保证售出速度；C5发货、Steam可交易/可上市时间以及款式宝石需买前核验。

## 数据、费用和币种

C5读取用户可见商品卡片的人民币价，按链接itemId匹配页面Nuxt已有的精确marketHashName，不猜测中文名，不主动调用C5隐藏接口。

Steam人民币报价读取公开priceoverview（appid=570、currency=23），只接受人民币符号；volume通常表示近期约24小时成交量，但接口未返回窗口元数据，不等于C5成交量。

Steam求购读取新版市场页面实际使用的公开orderbook接口。0.3.3不再强制匿名请求，让Tampermonkey使用浏览器正常会话；平台实际返回的eCurrency必须是23才参与人民币收益计算。请求能否携带正常会话受浏览器和扩展设置影响，登录本身不代表脚本已取得人民币盘口。0.1.0匿名请求返回MYR不能代表用户账号币种。

Steam页的补充按钮仅保存当前商品公开盘口及源时间戳，原币种编号、新鲜度均校验；不读取、复制或导出密码、Cookie、会话令牌或API Key。不会把非人民币盘口自动换汇。

挂售估算按Steam最低挂单价直接逆算手续费，不额外折让，也不以成交中位价替代挂单价。成交中位价仅用于价差核验。用户实测买家支付600元、卖家到账521.75元，已纳入回归校验；到账不是简单乘85%。旧版售价折让设置不再参与计算。以整数分寻找最大净额，使“净额 + floor(净额×5%) + floor(净额×10%) ≤ 买家支付总额”，两项费用各至少1分，间隙保守保留。实际费用以Steam卖出确认窗口为准。

成本包括C5卡片价及用户设置的额外成本。达标买入上限为“估算到账×参考成本比例−额外成本”，向下取整至分。余额增量是到账余额与现金成本的数值差，Steam钱包余额不能提现。

## 缓存与访问限制

报价与盘口5分钟有效，最多保存500个商品报价；设置、缓存、冷却在Tampermonkey本地。排序和筛选不会自动请求。跨标签租约降低重复请求，但GM存储非原子，建议一个标签页查询。

401/403、验证码或登录页响应暂停15分钟；429暂停30分钟；网络/格式错误停止本批，不自动重试。不绕过站点访问控制。C5跳转访问限制页时不继续注入或查询。

## C5官方API

API可批量补充C5价格、在售数量和求购统计，但需要另外开通访问权限。相关官方接口与开通条件见 [API.md](API.md)。此版本尚未调用需要app-key的API；没有未经验证地使用开发中接口，也没有要求把密钥提交到GitHub。

## 测试与限制

本地核心及真实C5商品DOM回放通过，覆盖42个卡片、成本比例方向、0.77参考买入上限、200元含边界门槛、立即卖出/挂售分级、币种拒绝、过期数据、排序筛选、429冷却及Steam页人民币盘口导入。

真实C5浏览器测试此前在初步识别与展示后跳转console-ban，完整在线测试未完成。用户已登录Chrome未向当前工具开放连接；未直接查看其当前页面，也未完成真实Tampermonkey的登录会话请求验证。Steam桥接的浏览器测试使用模拟人民币盘口，不能声称真实账号数据已验证。

仅支持C5刀塔2主列表及Steam刀塔2饰品页，新版Steam页面状态结构变化可能使桥接不可用。价格、交易限制、版本/宝石和流动性均可能变化，不能保证盈利或立即卖出。

Node.js运行 node tests.cjs；npm install 后，Windows Chrome可运行 npm run test:browser。默认浏览器测试完全使用本地快照和模拟请求，不访问用户登录会话。详见TESTING.md。

历史 reports/2026-10-07.md 是0.1.0、16:57左右的匿名公开报价样本，采用相反的“到账/成本”方向，不能当作0.3.3此刻的实时推荐。
