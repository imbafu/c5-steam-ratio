# C5 DOTA2 Steam 余额比例分析

在 C5 刀塔2列表页显示 `Steam人民币最低挂单价 / C5买入价`，比例越高越好。独立编写的 Tampermonkey 脚本，适用于 `https://www.c5game.com/dota2`，不自动购买、交易、翻页或登录。

## 安装

1. 浏览器安装 Tampermonkey，允许它在 C5 页面运行脚本。若浏览器提示需要用户脚本权限，按其提示启用。
2. 登录 GitHub 打开本私有仓库，下载 `c5-steam-ratio.user.js`。
3. Tampermonkey → 添加新脚本，替换默认内容为文件全文，保存。私有仓库 Raw 地址可能包含短期访问令牌，不适合做自动更新地址。
4. 打开 C5 刀塔2市场列表。页面商品列表上方应出现“C5 → Steam 余额”面板。
5. 点击“查询本页”。每批最多10件、20次公开请求，至少间隔5秒；结果逐项显示。点“停止”可停止后续请求，已发出的请求仍可能完成。

同时运行其他挂刀脚本可能冲突，请先停用它们。脚本无远程依赖，只允许访问 `steamcommunity.com`，无需 Steam 密码、API Key 或支付信息。

## 数据与计算

- C5：读取当前页面商品卡片 `.goodsCard .price p` 的人民币价格，按商品链接中的 itemId 对应页面已有 Nuxt 数据的 `marketHashName`。不按中文名模糊匹配，不主动查询 C5 接口。
- Steam 报价：公开 `market/priceoverview/?appid=570&currency=23&market_hash_name=...`，只接受含人民币符号的最低价、中位价和 `volume`。`volume` 通常为近24小时成交量，接口未提供时间窗口元数据；不等于 C5 成交量或在售量。
- 求购：使用 Steam 新版页面实际调用的公开 `/market/orderbook?q=Load&qp=[570,marketHashName]` 和 `x-valve-request-type: queryAction` 请求头。读取最高求购、总求购件数、顶档数量和最低挂单。
- **盘口币种必须检查。** 2026-10-07 本环境取得的盘口为 MYR（编号11），`currency=23` 未生效。脚本显示原币种求购价及盘口价差，绝不直接与 C5 人民币售价相除，绝不自动推测汇率。只有明确返回 CNY（编号23）的新鲜盘口才计算人民币求购费后比例。
- 挂单收益估算：人民币最低挂单价与成交中位价取低，默认再折让3%，然后扣 Steam 5% + DOTA2 10% 费用。不能简单用买家支付价乘0.85；脚本以整数分寻找 `净额 + floor(净额×5%) + floor(净额×10%) ≤ 买家总额` 的最大净额，两项费用各至少1分。间隙保守保留。实际手续费以 Steam 卖出确认窗口为准。
- `挂单费后比例 = 估算到账 / (C5买入价 + 单件额外成本)`；`余额增量 = 估算到账 - 总成本`。余额增量指现金转为 Steam 钱包余额的数值差，不能视为可提现现金利润。
- `人民币求购费后比例 = 最高求购扣费后到账 / 总成本`，用于单件立即卖出估算，不足以支持超出顶档数量的批量交易。
- `中位价偏差 = |最低挂单 - 中位价| / 中位价`；`盘口价差 = (最低挂单 - 最高求购) / 最低挂单`，两者含义不同。盘口价差在同币种盘口内计算。

## 推荐、排序和筛选

“挂单比例候选”要求：新鲜人民币报价、足够成交量、合理中位价偏差、费后比例达到阈值、C5价格低于上限、没有识别出的特殊属性风险。

“★ 买入核验候选”还要求：5分钟内的 **人民币** 求购盘口、求购费后比例达到阈值、盘口价差不超过阈值、顶档数量大于零。缺少任一关键字段均不推荐。无候选是合法结果。

默认门槛为挂单费后比例≥1.15、人民币求购费后比例≥1.05、近期成交量≥30、盘口价差≤5%、中位价偏差≤15%、C5售价≤500元。面板可调整并保存设置。排序在单独生成的结果列表中进行，避免移动 Vue 管理的商品节点；“只看候选”隐藏未符合全部条件的卡片。

## 频率、缓存与隐私

手动发起、单请求串行、每次至少5秒并有随机额外间隔；每批最多20次请求，不自动翻页。报价缓存30分钟，盘口5分钟。最多保留500个商品缓存。缓存、设置、冷却状态均存于 Tampermonkey 本地存储。

跨标签页使用共享队列租约和下一次请求时间，降低重复请求；GM存储不具备原子事务，不能保证多个标签同时点击时完全互斥，建议只在一个标签页查询。

HTTP 401/403、验证码或登录页响应暂停15分钟，429暂停30分钟；网络失败或无效数据立即停止本批，不自动重试。C5跳转至访问限制页时，脚本不继续查询、不注入该页面、不绕过限制。匿名 Steam 请求不主动发送账号登录凭据。

## 本地测试

Node.js运行 `node tests.cjs`。浏览器回放另需 `npm install`，安装Chrome后运行 `npm run test:browser`。默认浏览器路径是Windows的 `C:/Program Files/Google/Chrome/Application/chrome.exe`，其他环境请改测试文件对应路径。测试请求均为模拟；页面样本来自公开C5页面，已移除所有脚本，仅保留商品DOM和精简市场名映射。测试结果与截图写入 `research/`，不上传原始页面状态。

## 已知限制

接口未承诺稳定性，Steam新版市场正在变化。精确市场名缺失、页面结构变化或无人民币报价时停止估算。仅支持刀塔2主列表页；商品详情页、其它游戏和移动网页尚未支持。C5最小标价可能含补贴、预售或交易条件，买入前需核对实际支付价与转卖限制。不同宝石、款式、解锁程度和特殊属性可能影响可比性，脚本无法完全识别。最低挂单、最高求购及成交量会变化，冷却期/流动性可能导致实际到账下降。短时间高成交量也不等于没有异常交易。
